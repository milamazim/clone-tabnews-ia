# AGENTS.md

## Sobre o projeto

**clone-tabnews-ia** é uma reimplementação do [TabNews](https://tabnews.com.br) feita para o [curso.dev](https://curso.dev), construída com o auxílio de agentes de IA.

## Stack

- Next.js (App Router)
- React
- JavaScript puro (sem TypeScript)

As versões exatas estão no `package.json`.

## Comandos

- `npm run dev`: servidor de desenvolvimento
- `npm run build`: build de produção
- `npm run start`: roda o build de produção
